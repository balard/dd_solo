# Dragon dice -- 5 elements x 2 forms (drake, wyrm) = 10 dice, 12 faces each.
#
# Format:  header line  = "<element> <form>"
#          face lines   = "<face number 1-12> <Icon>"
#
# As in terrains.faces.txt, and UNLIKE the unit files, the leading number is the
# FACE NUMBER, not an icon count. A dragon face carries a fixed named ability
# rather than a count of result icons, so there is no count to record.
#
# Vocabulary: Jaws, Breath, Claw, Belly, Wing, Tail, Treasure. See data/ICONS.md.
#
# The layout is the same for all five elements of a form -- only Breath's effect
# differs by element, and the importer checks that the ten transcriptions agree.
# The two forms differ by more than one face: a wyrm spends the drake's two Wings
# on a third Tail and a Treasure.
#
# Source: full rules p. 20 for the icon effects; the layouts are transcribed from
# real dice (neither rulebook prints them).
