# Coral Elves unit die faces.
# Source: Dice Commander die info and face-art paths, transcribed 2026-09-29.
# Format: a die header line (URL or "<class>-<size>"), then one "<count> <Icon>" line per face.
# d6 units have 6 faces, monsters (d10) have 10. See data/ICONS.md.
#
# Face 1 is the ID face; the source lists the other faces only. A monster face's art is
# '<icon>-m.svg' with no count in it, so every monster face is written as 4 -- which is
# right for every normal icon (invariant 7). Of the six new SAIs only Entangle and Wave
# read X; Tail's two melee, Swallow's one unit, Ferry's four health-worth and Hypnotic
# Glare are fixed by their text, so the 4 on those faces is never read.
#
# Sharpshooter was listed with six faces; the owner of the dice corrected it to the five
# below (2 Melee, not 2 Maneuver and 2 Missile).
#
# Art, for `npm run art` (v2 Phase 5g) -- the source's own notes on which image a die uses:
#   maneuver variant 1 (maneuver-1-<n>.svg): heavy melee, light melee, missile, Evoker, monsters
#   maneuver variant 2 (maneuver-2-<n>.svg): cavalry, Conjurer
#   fly variant 1 (fly-1-<n>.svg / fly-1-m.svg): Eagle Knight, Gryphon, Sprite Swarm
#   fly variant 2 (fly-2-m.svg): Leviathan
#   the other faces: melee-<n>, missile-<n>, magic-<n>, save-<n>, sais/<name>-<n>, and '-m' on a monster
